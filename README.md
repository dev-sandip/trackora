# 🚚 Trackora

### Tracking delivery agents, one WebSocket at a time. 📍

> I don't know if I'm gonna finish this project or if it's gonna finish me. 💀

**Trackora** is a little project I'm building to learn WebSockets by creating an app that tracks delivery agents in real time.

The goal? Make dots move on a map, understand how real-time communication works, and hopefully not lose my sanity in the process.

## 🎯 The Mission

- 📍 Track delivery agents in real time.
- ⚡ Learn and experiment with WebSockets.
- 🔄 Make live location updates happen without constantly refreshing the page.
- 🧠 Figure out how real-time applications actually work.
- 🫠 Survive the bugs along the way.
